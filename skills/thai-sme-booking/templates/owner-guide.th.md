## 1. ระบบทำอะไรให้ร้านบ้าง
- ลูกค้ากด **"จองคิว"** ในเมนู LINE → เลือกบริการ วัน เวลา → ระบบกันคิวไว้ให้ 20 นาที
- ถ้ามีมัดจำ ลูกค้าได้ **QR พร้อมเพย์ยอดตรง** → โอน → ส่งสลิปในแชท → ระบบ **ตรวจสลิปกับธนาคาร** และยืนยันคิวให้อัตโนมัติ
- ลูกค้าได้ **ข้อความเตือนนัด** ใน LINE ก่อนวันนัด 1 วัน
- คำถามทั่วไป (ราคา เวลาเปิด แผนที่ ฯลฯ) **บอทตอบให้** ส่วนคำถามอื่นจะรอร้านตอบในแชทเหมือนเดิม
- ทุกการจองขึ้นใน **Google Sheets** และ **Google Calendar**

## 2. ดูคิวประจำวัน
เปิดตารางการจอง → แท็บ **Bookings** (หรือเปิดปฏิทิน Google ในมือถือ)

| สถานะ | ความหมาย | ร้านต้องทำอะไร |
|---|---|---|
| 🟨 PENDING_DEPOSIT | จองแล้ว รอโอนมัดจำ | ไม่ต้องทำอะไร (ครบ 20 นาทีไม่โอน ระบบปล่อยคิวเอง) |
| 🟩 CONFIRMED | ยืนยันแล้ว | เตรียมรับลูกค้า |
| 🟥 NEEDS_REVIEW | สลิปมีปัญหา ต้องตรวจ | ดูหัวข้อ 3 |
| ⬜ EXPIRED / CANCELLED | หมดเวลา / ยกเลิก | — |
| 🟦 COMPLETED / ⬜ NO_SHOW | มาแล้ว / ไม่มาตามนัด | เปลี่ยนเองได้ (ใช้คิดสถิติ) |

## 3. เมื่อได้แจ้งเตือน "⚠️ สลิปต้องตรวจสอบ"
1. อ่านเหตุผลในข้อความ (เช่น ยอดโอนไม่ครบ, สลิปเคยใช้แล้ว, ชื่อผู้รับไม่ตรง)
2. เช็กในแอปธนาคารของร้านว่าได้รับเงินจริงไหม
3. **ได้รับเงินถูกต้อง** → ในชีตเปลี่ยนสถานะแถวนั้นเป็น **CONFIRMED** → ลูกค้าได้ข้อความยืนยันอัตโนมัติ
4. **ไม่ได้รับเงิน/ผิดปกติ** → คุยกับลูกค้าในแชท แล้วเปลี่ยนเป็น **CANCELLED**

> ⚠️ ระบบไม่ปฏิเสธลูกค้าเองเด็ดขาด ทุกกรณีที่ไม่แน่ใจจะส่งให้ร้านตัดสินใจ

## 4. ปิดรับคิวบางช่วง / วันหยุด
- **หยุดทั้งวัน:** เพิ่มวันที่ในแท็บ **Holidays** หรือสร้างนัด "ทั้งวัน" ในปฏิทิน Google
- **ไม่ว่างบางช่วง** (ธุระ พักเที่ยง): สร้างนัดในปฏิทิน Google ช่วงนั้น → ระบบปิดคิวให้อัตโนมัติ
- **ลูกค้า walk-in / จองทางโทรศัพท์:** สร้างนัดในปฏิทิน Google เพื่อกันคิว

## 5. แก้ราคา บริการ หรือข้อมูลเว็บไซต์
| อยากแก้ | แท็บ |
|---|---|
| ราคา / เวลา / มัดจำ ของบริการ, เพิ่ม-ปิดบริการ | Services (ปิดบริการ: ช่อง active = FALSE) |
| เวลาเปิด-ปิด | Hours |
| คำตอบของบอท | FAQ |
| ข้อความหน้าเว็บ ทีมงาน รีวิว รูปผลงาน | Site / Staff / Reviews / Gallery |

แก้เสร็จแล้วกดเมนู **🗓️ ระบบจอง → 🌐 อัปเดตเว็บไซต์** (รอ 1–2 นาที)
หน้าจองคิวใน LINE อัปเดตทันทีโดยไม่ต้องกด

> อย่าแก้แท็บ **Settings** และห้ามลบหัวคอลัมน์ (แถวที่ 1) ของทุกแท็บ หากไม่แน่ใจ ติดต่อผู้ดูแลระบบ

## 6. ดูยอดประจำเดือน
เมนู **🗓️ ระบบจอง → 📊 สรุปยอดเดือนนี้** → แท็บ **Report** แสดงจำนวนการจอง ยอดตามราคาบริการ มัดจำที่ได้รับ อัตราไม่มาตามนัด และบริการยอดนิยม

## 7. ตอบแชทลูกค้า
ตอบใน **LINE OA Manager** (แอป "LINE Official Account") ตามปกติ บอทตอบเฉพาะคำถามที่อยู่ในแท็บ FAQ ข้อความอื่นรอร้านตอบ
เพิ่มทีมงานให้รับแจ้งเตือน: ให้ทีมงานพิมพ์ `/owner รหัส` ในแชทของร้าน (ขอรหัสจากผู้ดูแลระบบ)

## 8. ค่าใช้จ่ายรายเดือนของร้าน
- LINE OA: ฟรี (ถ้าข้อความเตือนนัดเกินโควต้า ระบบจะส่งอีเมลรายชื่อลูกค้าให้โทรเตือนแทน และผู้ดูแลจะแนะนำแพ็กเกจที่เหมาะสม)
- ระบบตรวจสลิป: ตามแพ็กเกจที่สมัครในชื่อร้าน
- Google / เว็บไซต์: ฟรี · โดเมน (ถ้ามี): รายปี
